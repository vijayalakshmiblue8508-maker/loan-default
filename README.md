# Loan Default Prediction System

## Project Overview

The Loan Default Prediction System is a data analytics and machine learning project designed to analyze borrower information and identify factors that influence loan repayment behavior. The system performs Exploratory Data Analysis (EDA), Risk Analysis, and Linear Regression modeling to support better loan approval decisions and reduce financial risk.

## Features

* Data Cleaning and Preprocessing
* Missing Value Analysis
* Duplicate Record Removal
* Loan Status Analysis
* Income Analysis
* Loan Amount Analysis
* Interest Rate Analysis
* Risk Classification
* Correlation Analysis
* Linear Regression Modeling
* Loan Amount Prediction
* Interactive Data Visualization

## Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly
* Scikit-Learn
* Faker

## Dataset Information

The dataset contains borrower and loan-related information including:

* Loan Amount
* Loan Term
* Interest Rate
* Annual Income
* Employment Length
* Home Ownership
* Loan Purpose
* Loan Grade
* Loan Status

The dataset is used to analyze borrower behavior and identify potential loan default risks.

## Objectives

* Understand borrower financial behavior
* Analyze factors affecting loan repayment
* Identify high-risk borrowers
* Perform risk classification
* Build a predictive model using Linear Regression
* Support data-driven loan approval decisions

## Machine Learning Model

Model Used: Linear Regression

### Input Features

* Annual Income
* Interest Rate
* Loan Term

### Target Variable

* Loan Amount

### Evaluation Metric

* R² Score

The model is trained using historical loan data and predicts loan amounts based on borrower financial information.

## Risk Classification

Borrowers are classified into:

### Low Risk

Interest Rate less than 10%

### Medium Risk

Interest Rate between 10% and 18%

### High Risk

Interest Rate greater than 18%

This classification helps identify potential loan defaulters and supports better risk management.

## Business Insights

The system helps financial institutions:

* Identify high-risk borrowers
* Analyze borrower income patterns
* Understand loan demand trends
* Improve credit risk assessment
